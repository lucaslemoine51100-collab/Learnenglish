# Learnenglish — Assistant Comics (iPad Pro)

Projet d'assistant pédagogique pour lire des comics en anglais sur iPad Pro. L'assistant tient dans une fenêtre flottante : détection des bulles, traduction française, explications grammaticales, historique de progression.

## État actuel : étude de faisabilité

- Rapport : [docs/etude-faisabilite-ipad.md](docs/etude-faisabilite-ipad.md)
- Verdict : **GO conditionnel** pour les tests sans coût (Phase 0 sur l'iPad, Phase 1A dans Swift Playgrounds). **Aucune dépense** avant la validation sur l'appareil.
- Point d'attention : Marvel Unlimited s'arrête en décembre 2026 au profit de « Marvel Comics powered by WEBTOON ». Il faut valider le changement d'application cible.

Aucun code applicatif n'est développé à ce stade.
